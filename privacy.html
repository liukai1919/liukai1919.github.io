vedio studio 隐私政策

更新日期：2026-10-06

vedio studio 是 Kai Liu 个人使用的视频发布工具，只用来把我自己制作的视频上传到我自己的 YouTube 频道，不对外提供服务。

访问哪些数据

工具通过 Google OAuth 请求 YouTube 权限，仅用于上传视频、设置封面、把视频加入播放列表，以及查看本人频道的上传列表以避免重复上传。

数据如何保存和共享

OAuth 授权令牌只保存在我本人的电脑上，不上传到任何服务器，不与任何第三方共享。工具不收集、不存储其他任何人的数据。

撤销授权

可随时在 Google 账号权限页面 撤销本工具的访问权限。

YouTube API 服务

本工具使用 YouTube API Services。使用即表示同意 YouTube 服务条款，并适用 Google 隐私权政策。

vedio studio Privacy Policy

vedio studio is a personal tool used by Kai Liu only to upload his own videos to his own YouTube channel. It is not offered to anyone else.

It requests YouTube access through Google OAuth solely to upload videos, set thumbnails, add videos to playlists, and list the channel's own uploads to avoid duplicates. The OAuth token is stored only on the owner's computer and is never sent to any server or shared with third parties. No data about anyone else is collected or stored.

Access can be revoked at any time at myaccount.google.com/permissions. This tool uses YouTube API Services; see the YouTube Terms of Service and the Google Privacy Policy.
